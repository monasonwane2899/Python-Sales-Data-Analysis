# Python Sales Data Analysis Project

## Project Overview

This project focuses on analyzing sales data using Python. The objective is to clean the dataset, perform Exploratory Data Analysis (EDA), analyze sales performance, visualize trends, and generate meaningful business insights.

## Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Dataset Information

The dataset contains sales transaction information, including:

* Invoice Number
* Customer ID
* Category
* Quantity
* Price
* Invoice Date
* Shopping Mall

## Project Workflow

### 1. Data Loading

* Imported the sales dataset using Pandas.
* Displayed the first and last five records.
* Checked dataset dimensions and column information.

### 2. Data Cleaning

* Checked missing values.
* Identified and removed duplicate records.
* Removed unnecessary spaces from text columns.
* Converted invoice dates into datetime format.
* Checked invalid quantity and price values.

### 3. Exploratory Data Analysis (EDA)

* Analyzed product categories.
* Identified shopping malls.
* Calculated total quantity sold.
* Calculated total sales revenue.
* Calculated average transaction revenue.

### 4. Sales Analysis

* Category-wise revenue analysis.
* Shopping mall-wise revenue analysis.
* Category-wise quantity analysis.
* Monthly revenue trend analysis.
* Identified highest and lowest performing categories.

### 5. Data Visualization

Created the following visualizations using Matplotlib:

* Category-wise Revenue – Bar Chart
* Shopping Mall-wise Revenue – Bar Chart
* Monthly Revenue Trend – Line Chart
* Category-wise Revenue Share – Pie Chart
* Transaction Revenue Distribution – Histogram

### 6. Business Insights

Generated insights to identify:

* Highest revenue category.
* Lowest revenue category.
* Highest revenue shopping mall.
* Highest revenue month.
* Total sales revenue.
* Total quantity sold.

### 7. Data Export

Exported the cleaned dataset into a CSV file named `sales_data_cleaned.csv`.

## Project Files

* Dataset: Original and cleaned sales data ('sales_data.csv', 'sales_data_cleaned.csv').
* Python_Code: Python source code ('SalesDataAnalysis.ipynb').
* Visualizations: Generated charts ('category_wise_revenue.png', 'mall_wise_revenue.png', 'monthly_revenue_trend.png', 'category_revenue_share.png', 'revenue_distribution.png').


## Conclusion

This project helped analyze sales performance, identify revenue trends, understand customer purchasing patterns, and generate business insights using Python.

It demonstrates practical skills in data cleaning, data analysis, data visualization, and Exploratory Data Analysis (EDA).
